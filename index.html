About this build

J.A.R.V.I.S. is a local retrieval-based assistant. It can search uploaded knowledge and saved memories, perform selected built-in tasks and learn approved facts. It is not a general-purpose neural language model and cannot guarantee answers to arbitrary questions without a model or external service.
